\# KapTester V2



Capacitance Tester built as AP2 (Abschlussprüfung Teil 2) project.



\## Hardware

\- ATmega328P microcontroller

\- Custom PCB (designed with KiCad)

\- SSD1306 OLED display (I2C)

\- LM317 adjustable voltage regulator

\- USB powered



\## Firmware

| Firmware | Description |

|----------|-------------|

| fw1\_produktion | Production firmware |

| fw2\_test | Test firmware |

| fw3\_Voll | Full feature firmware |



\## Repository Structure
